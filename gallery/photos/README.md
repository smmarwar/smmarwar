# Gallery photo uploads

Upload your photos directly into this folder using GitHub's **Add file → Upload files**.

Supported formats: JPG, JPEG, PNG, WEBP, GIF and AVIF.

After committing the upload, open the Gallery page:
https://smmarwar.github.io/smmarwar/gallery.html

The gallery reads image files from this folder automatically. It preserves each image's original proportions, so square, landscape (16:9) and portrait photos display at their natural aspect ratio.

Tip: use simple file names such as photo-01.jpg, event-02.png.
